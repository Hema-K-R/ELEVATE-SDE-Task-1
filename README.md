# CredVault — Reference-Style Frontend

A responsive frontend inspired by the supplied CredVault demo video. It uses **HTML, CSS and vanilla JavaScript**, so it can be opened and understood easily in VS Code.

## Pages and features

- Home / landing page
- Request Certificate form
- Track Application page
- Admin Login page
- Admin Dashboard with Applications and Certificates tabs
- Verify Certificate page
- Demo actions: submit requests, track status, approve/reject applications, issue certificates and revoke certificates
- Responsive dark theme with a **teal / emerald accent palette** instead of the original blue-purple accents

## Run in VS Code

1. Download and extract the ZIP.
2. Open the extracted `CredVault-Reference-Frontend` folder in VS Code.
3. Install the **Live Server** extension if it is not installed.
4. Right-click `index.html` and select **Open with Live Server**.
5. The site opens in your browser. You can also open `index.html` directly, but Live Server is recommended.

## Important

This is a frontend-only demo. There is no backend, database, real authentication, or permanent storage. The sample data and any changes exist in JavaScript memory and reset when the page is refreshed. The supplied video was used as a visual reference; spacing and interactions have been recreated as a close frontend interpretation rather than a pixel-perfect copy.
